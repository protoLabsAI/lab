# reasoning v2 — parametric, solver-verified, exact-match

Phase 3 suite (FOCUS.md). 24 tasks, 6 families × 4 (easy, easy, medium, hard),
generated by `generators/gen_v2.py --seed 20260702`. Zero LLM judge.

| family | measures | grading |
|---|---|---|
| arith | multi-step quantity tracking w/ distractor numbers | match:number |
| sequence | rule induction (alt-add / 2nd-diff / interleaved) | match:number |
| machine | exact multi-step state tracking (register program) | match:number |
| schedule | constraint satisfaction, unique assignment | match:all_of (partial credit) |
| grid | zebra-style cross-attribute deduction | match:regex on ANSWER line |
| knights | self-referential boolean deduction | match:all_of (partial credit) |

Properties:
- **Solver-verified:** every instance's ground truth re-derived independently;
  puzzle families (schedule/grid/knights) brute-force-checked for a UNIQUE
  solution, with redundant clues pruned. (Fun constraint discovered en route:
  knights&knaves with only "X is a knight/knave" statements can never be unique
  — the model set is closed under the global knight↔knave flip. Compound
  statements are required to break the symmetry.)
- **Contamination-resistant:** `--seed N` regenerates a fresh, never-published
  instance set. If a set's numbers have been published, bump the seed for the
  next baseline round and note it in `evals/baselines/`.
- **Format contract:** tasks demand a final `ANSWER: ...` line; `number` mode
  takes the last number, `all_of` gives partial credit per correct assignment.
  A capable model that solves but misformats loses points — acceptable
  (format-following is in scope), monitored during calibration.
- Run **thinking-on** (`--thinking`) per lab policy for reasoning evals.

v1 (`logic.v1.yaml.retired`) was 5 LLM-judged tasks, ceilinged at 0.93–1.00
across the ladder — kept out of the runner glob, retained for history.

## Calibration outcome (2026-07-02, Ornith-35B, thinking-on)

First run ceilinged (23/24). Hardened every hard tier — 30-op register traces,
3-stream interleaved sequences, n=7 knights/schedule, relational-only grids —
and it **still** ceilinged (mean 0.962, 21/24 ≥ 0.9). Finding: a 35B thinking
model saturates bounded single-turn reasoning regardless of difficulty. See
`evals/PHASE3_RESULTS.md`.

Consequences applied here:
- **This suite's job is the ≤9B ladder** (the lab's north star), not 35B. It
  will spread 4B < 9B; that run is pending a GPU plan (task #9). It stays as a
  35B *regression floor*, not a 35B discriminator.
- **All families converted to multi-value / partial-credit answers** so even a
  35B leaves headroom: arith (two item counts), machine (all 3 registers),
  sequence-hard (two terms), schedule + knights + grid (full assignment via
  `all_of`). Where the 35B already left headroom it was exactly these — arith
  two-count 0.50, schedule 0.75–0.83.
